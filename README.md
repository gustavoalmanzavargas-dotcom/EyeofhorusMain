## 🛡️ Core Capabilities

- **Unified Threat Telemetry & SIEM**: Real-time log ingestion, normalized event streams, and behavioral anomaly detection.
- **MITRE ATT&CK® Matrix Mapping**: Live tactical correlation and technique mapping across active security alerts.
- **AI-Powered Incident Triaging**: Autonomous incident summarization, severity scoring, and containment playbooks powered by Gemini.
- **Agent Mesh & Endpoint Monitoring**: Dynamic fleet telemetry with health status, OS tracking, and agent volume distribution.
- **Dark/Light Mode Theme Architecture**: Theme-adaptive vector iconography and high-contrast accessibility across all security dashboards.
- **Whitelabel & Multi-Tenant Branding**: Customizable organization seals, MSSP tenant profiles, and custom CSS color schemes.
